## 8. Konvensi / DoD yang Diikuti
Setiap flow menempuh Definition of Done ketat (flow-centric v4):
1. Spec JSON (`_flows/*.flow.json`) dengan endpoint **grounded** ke manifest backend.
2. POC Python (`tests/*_test.py`) → jalankan sampai **ALL PASS** + **self-cleanup** (DB pristine).
3. Bug High → **fix + verifikasi**; bug minor dicatat/diperbaiki bila aman.
4. Dokumen flow ≥ 800 baris memenuhi F1–F10; `validate_flow.py` **LULUS 10/10**.
5. Berkas QA (`_qa/*_bugs.md`) + registrasi `00_INDEX.md` & `BUG_REGISTER.md`.
6. Verifikasi independen via `testing_agent_v3` (backend + UI; upload/drag-drop di-skip).
